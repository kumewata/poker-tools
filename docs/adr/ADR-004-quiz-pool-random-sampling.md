# ADR-004: クイズ問題プール拡充とランダムサンプリング出題

## ステータス

Accepted（ADR-003 を補完）

## コンテキスト

ADR-003 で導入したクイズ機能は6問のみで、1回のセッションで全問を消化してしまう。繰り返しプレイの動機がなく、学習ツールとしての価値が限定的だった。

ranges.ts には13シナリオ・500以上のハンドコンボが定義されているが、クイズで使用していたのは5シナリオのみ。特に CO ポジションの問題が0問、Blinds は1問しかなく、レンジデータの活用率が低かった。

問題数を増やすにあたり、以下の課題があった:

- 40〜50問を手作業で作成するのはミスが起きやすい（正解アクションの誤り、レンジデータとの不整合）
- 問題の品質（解説の正確性、ハンド選定のバランス）を一定に保つ必要がある
- 全問出題すると1セッションが長くなりすぎる

## 決定

### 1. 問題プールを45問に拡充し、毎回20問をランダムサンプリングして出題する

```typescript
const QUIZ_SIZE = 20;
const shuffled = shuffle(quizQuestions).slice(0, QUIZ_SIZE);
```

- 既存の Fisher-Yates シャッフルを活用し、先頭20問を切り出す
- 全13シナリオを最低1問ずつカバー（EP:10, CO:11, BTN:10, Blinds:14）

### 2. 正解アクションは ranges.ts のレンジデータに基づいて機械的に判定する

- ハンドが reraise レンジに含まれる → リレイズ/3-Bet が正解
- ハンドが flat レンジに含まれる → コールが正解
- ハンドが raise レンジに含まれる → レイズが正解
- どのレンジにも含まれない → フォールドが正解

### 3. 問題生成ワークフローをスキル+サブエージェントとして定義する

- `.claude/skills/quiz-gen/SKILL.md`: 生成ワークフロー全体の管理（カバレッジ分析 → 生成計画 → エージェント呼び出し → レビュー → 統合）
- `.claude/agents/quiz-question-generator.md`: シナリオ単位で問題を生成するサブエージェント（最大3並列）

## 理由

- **ランダムサンプリング**: 全問出題ではなく20問ピックアップにすることで、1セッション5〜10分を維持しつつ、繰り返しプレイで毎回異なる問題が出る。45問プールなら毎回約半分が入れ替わる
- **レンジデータ駆動**: エージェントのポーカー知識ではなく、ranges.ts のデータを正解の根拠とすることで、レンジ表との一貫性を担保。レンジ表を更新すれば問題の正解も自動的に追従できる
- **スキル+エージェント分離**: シナリオ単位でエージェントを並列起動することで、各問題の生成品質を高めつつ高速化。メインコンテキストの消費も抑制される
- **代替案（全問出題 + ページネーション）**: 45問を5問ずつ区切って出題する案もあったが、毎回同じ順序だと学習効果が下がる。ランダムサンプリングの方がシンプルで効果的

## 影響

- 問題追加は引き続き `quiz-data.ts` への追記のみで完結する（ADR-003 の設計を維持）
- quiz-gen スキルにより、今後の問題追加は「シナリオ指定 → エージェント生成 → レビュー → 統合」のパイプラインで半自動化される
- 20問固定のため、将来的に問題数が100問を超えても出題時間は一定
- シナリオ別・難易度別のフィルタリング出題は未実装（スコープ外として明示的に除外）
- QUIZ_SIZE を変更するだけで出題数を調整可能
