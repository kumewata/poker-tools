# クイズ問題生成エージェント

ポーカーのプリフロップ戦略クイズ問題を生成する。

## 入力

呼び出し時のプロンプトで以下が指定される:

- 対象シナリオ（例: `ep-open`, `btn-vs-loose`）
- 生成する問題数
- 避けるべきハンド（既存問題と重複しないよう）

## ワークフロー

### 1. データ読み込み

以下のファイルを読み込む:

- `src/data/ranges.ts` — レンジ定義（ハンドリスト、シナリオ、ポジション）
- `src/data/quiz-data.ts` — 既存の問題（重複回避のため）

### 2. ハンド選定

指定シナリオのレンジデータから、以下のカテゴリのハンドをバランスよく選ぶ:

| カテゴリ | 説明 | 正解アクション | 例 |
|---------|------|--------------|-----|
| 明確にレンジ内 | レイズ/リレイズ/フラットのいずれかに含まれる | そのアクション | AKs → Raise |
| 明確にレンジ外 | どのアクションにも含まれない | フォールド | 72o → Fold |
| ボーダーライン | レンジの端にあるハンド | 含まれるアクション | A9s が Flat に入っている → Call |
| スーテッド/オフスート差 | 同ランクでアクションが変わる | それぞれの正解 | A5s→Raise, A5o→Fold |

### 3. 正解アクション判定ロジック

シナリオのレンジデータに基づいて判定する:

1. ハンドが `reraise` レンジに含まれる → 正解は「リレイズ (3-Bet)」または「4-Bet」
2. ハンドが `flat` レンジに含まれる → 正解は「コール」
3. ハンドが `raise` レンジに含まれる → 正解は「レイズ」
4. どのレンジにも含まれない → 正解は「フォールド」

### 4. 問題生成

各ハンドに対して以下を生成:

```typescript
{
  id: number,               // 既存の最大ID + 1 から連番
  situation: string,        // シナリオに合った状況説明（日本語）
  hand: string,             // カード表記（例: "A♠K♥"）
  position: string,         // ポジション名（日本語）
  options: string[],        // 3つの選択肢
  correctIndex: number,     // 正解のインデックス
  explanation: string,      // 解説（日本語、2-3文）
  rangePositionId: string,  // ポジションID
  rangeScenarioId: string,  // シナリオID
}
```

### 5. 状況文（situation）のバリエーション

同じシナリオでも状況文に変化をつける:

**オープンレイズ系**:
- 「全員フォールドしてあなたの番が来た。」
- 「UTGからCOまで全員フォールドした。」
- 「タイトなテーブルで、あなたの前は全員フォールドした。」

**対ルース系**:
- 「ルースなプレイヤーがレイズし、2人がコールした。」
- 「頻繁にレイズするプレイヤーが$12にレイズした。」
- 「アグレッシブなプレイヤーがオープンレイズした。」

**対タイト系**:
- 「タイトなプレイヤーがUTGからレイズした。」
- 「普段リンプばかりのプレイヤーがレイズしてきた。」

**ブラインドディフェンス系**:
- 「BTNが$10にレイズした。」
- 「COがスティールレイズをしてきた。」

### 6. 選択肢（options）の構成

正解アクションに応じて適切な3択を構成する:

- オープンレイズ判断: `["フォールド", "コール（リンプ）", "レイズ"]`
- 3-Bet判断: `["フォールド", "コール", "リレイズ (3-Bet)"]`
- 4-Bet判断: `["フォールド", "コール", "4-Bet（リレイズ）"]`
- ディフェンス判断: `["フォールド", "コール", "リレイズ (3-Bet)"]`

### 7. 解説（explanation）の書き方

- ハンドの強さとポジションの関係を説明する
- なぜそのアクションが正しいかを「期待値」「ドミネート」「ポジション」の観点から述べる
- レンジ内/外であることの根拠を示す
- 2〜3文で簡潔に

### 8. カード表記

スートは以下の記号を使う:
- ♠ (スペード), ♥ (ハート), ♦ (ダイヤ), ♣ (クラブ)

ハンドのスート割り当て:
- スーテッドハンド: 同じスートを2枚（例: A♠K♠）
- オフスートハンド: 異なるスートを2枚（例: A♠K♥）
- ポケットペア: 異なるスートを2枚（例: J♠J♥）

## 出力形式

TypeScript の配列リテラルとして、`QuizQuestion[]` 形式で出力する。
コードブロック内に記述し、そのまま quiz-data.ts に貼り付けられる形にする。
